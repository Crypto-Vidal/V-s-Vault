# 🚀 AI NEXUS - Holographic Personal Website

A futuristic, Iron Man-inspired personal website for an AI consultant and app builder, featuring cutting-edge holographic effects, neon gradients, and glassmorphism design.

## ✨ Features

### 🎨 Design
- **Dark Theme**: Deep space background (#05080B) with neon accents
- **Holographic Effects**: Iron Man-style glowing panels and interfaces
- **Neon Gradients**: Cyan to green gradient (#00F0FF → #00FF8E)
- **Glassmorphism**: Frosted glass panels with backdrop blur
- **3D Elements**: Rotating cube animations and depth effects
- **Floating Particles**: Dynamic background particle system
- **Grid Overlay**: Animated holographic grid pattern

### 📱 Pages
1. **Home** - Hero section with stats, services preview, and CTA
2. **About** - Personal story, approach, and expertise areas
3. **Services** - Detailed breakdown of AI & automation services
4. **Skills** - Technical skills with animated progress bars
5. **Portfolio** - Showcase of projects and custom apps
6. **Tools** - Featured custom applications (Ballistics Test, Knock Knock, AI Focus Group, Crypto Tools)
7. **Contact** - AI assessment questionnaire integration and contact methods

### 🎯 Custom Applications
The website features placeholders for custom-built Vercel-deployed apps:
- **Ballistics Test** - Advanced ballistics calculator
- **Knock Knock** - Door-to-door sales assistant
- **AI Focus Group** - Intelligent focus group platform
- **Crypto Tools Suite** - Cryptocurrency analysis toolkit

### 🌐 Technology Stack

#### Frontend
- **HTML5** - Semantic markup
- **CSS3** - Custom properties, Grid, Flexbox, animations
- **JavaScript (ES6+)** - Vanilla JS for interactivity
- **Google Fonts** - Orbitron & Rajdhani

#### Effects & Animations
- CSS Keyframe Animations
- Intersection Observer API
- Smooth scrolling
- Particle effects
- Progress bar animations
- Counter animations
- Hover effects with glows

#### Responsive Design
- Mobile-first approach
- Breakpoints: 1024px, 768px, 480px
- Touch-friendly navigation
- Adaptive typography

## 🚀 Getting Started

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Crypto-Vidal/V-s-Vault.git
cd V-s-Vault
```

2. Open `index.html` in your browser or use a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve

# Using VS Code Live Server
# Right-click index.html → Open with Live Server
```

### Deployment

#### Vercel (Recommended)
```bash
vercel deploy
```

#### Netlify
```bash
netlify deploy
```

#### GitHub Pages
1. Push to GitHub
2. Go to Settings → Pages
3. Select branch and root folder
4. Save

## 🔧 Customization

### Update Contact Information
Edit the contact methods in `contact.html`:
- Email address
- Phone number
- Social media links
- AI assessment questionnaire URL

### Add Custom Apps
In `portfolio.html` and `tools.html`, update the `href` attributes with your deployed Vercel app URLs.

### Modify Colors
Update CSS variables in `css/styles.css`:
```css
:root {
    --bg-dark: #05080B;
    --cyan: #00F0FF;
    --green: #00FF8E;
}
```

### Change Fonts
Replace Google Fonts in HTML `<head>`:
```html
<link href="https://fonts.googleapis.com/css2?family=YourFont&display=swap" rel="stylesheet">
```
