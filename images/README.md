# Images Directory

## AI Assistant Background Image

Place your AI assistant background image as `ai-assistant-bg.jpg` in this directory.

The image should be:
- A high-quality image of an AI assistant or futuristic robot
- Recommended size: 1200x800 or larger
- Format: JPG or PNG (if PNG, update the CSS file extension)

The image will be displayed as a background on the AI Customer Assistant service card on the home page with a blur and darkening effect to maintain text readability.
